# Okonkwo Lab website

Static-site source for the Okonkwo Lab (marine bioacoustics).

Paper metadata lives in `content/papers/` as Markdown files with YAML front
matter. Build the site with the project's static-site generator after editing
an entry.

## Layout

- `content/papers/` - one Markdown file per publication
- `config.yaml` - site configuration
- `index.md` - landing page
- `static/style.css` - styles
